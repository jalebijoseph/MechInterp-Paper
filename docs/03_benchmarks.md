## Why each was picked

* **False belief / Hi-ToM** test the lens before any multi-agent claim. If J-space does not
  hold the protagonist's belief on a single-model ToM task, a null result in the agent
  experiments is uninformative. Kosinski's tasks are the standard behavioural test; Hi-ToM
  adds higher orders ("where does A think B thinks...").
* **NARCBench** is the closest prior work (proposal §3). Its detectors probe each
  colluder's own activations. We ask a complementary question: what does an *honest*
  agent's J-space contain while it reads a colluder's message? Replaying the released
  transcripts gives realistic deception without generating new collusion runs.
* **MACE** (Choi et al. 2026, arXiv 2607.11250) has not released code or data yet (the
  repo says "will be released soon"). Exp. 3's bandit variant reproduces its setting:
  repeated peer selection with outcome feedback, measuring lock-in.

## Benchmarks considered but not wired in

* **OpenToM** (`SeacowX/OpenToM`) has longer narratives with attitude and fullness
  questions. It would be a good second Exp. 0 source.
* **FANToM** (multi-party conversations with information asymmetry) fits the
  multi-agent framing best but is gated on the Hub. Add a loader once access is granted.
* **ToMi** and the Kosinski originals are gated or on OSF. The generator above covers
  the same task structure.

## Scoring the lens on a benchmark

For each item, the answer position is the last prompt token (after an `Answer:` prefill).
For both the belief word and the reality word, we take the best rank over workspace
layers there. Reported per framing and per false-belief vs control:

* `accuracy`: the model's own answer
* `belief_mrr`, `true_mrr`: reciprocal rank in J-space
* `belief_beats_truth`: fraction of false-belief items where the belief outranks reality
  (should be well above 0.5 if J-space carries the belief)
