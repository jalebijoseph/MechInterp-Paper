# afrj-jacobian-peers-analysis

This repository will contain the implementation of the research proposal **Internal Representations of Theory of Mind Across Agents via the Jacobian Lens**.

The project uses the Jacobian lens (J-lens) from Anthropic's J-space work to study whether LLM agents internally represent what their peers know and are doing in multi-agent workflows: collaboration, imposter detection, and orchestrator peer selection.
